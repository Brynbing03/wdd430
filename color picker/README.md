# Color Picker Collection

Four independent implementations of the same 128-square color picker:

- `vanilla/` — plain HTML, CSS, and JavaScript
- `svelte/` — Svelte + Vite
- `react/` — React + Vite
- `angular/` — Angular CLI-style standalone app

Each picker uses a 16-column by 8-row grid (128 squares), lets you select a color, and displays the selected color's name and hex value.

## Running the examples

Open `vanilla/index.html` directly in a browser. For the framework versions, run `npm install` and then `npm run dev` from the corresponding folder.
